# 🚀 LuzEngine
Motor de juegos **propio y ligero** con soporte **2D y 3D**, creado en México.

✅ Lenguaje propio: **LuzScript / Luzmax** (todo en español)
✅ Basado en Godot 4.7 Estable
✅ Listo para exportar a **Android (APK)**
✅ Optimizado para usar solo con celular
✅ Interfaz y comandos en español

Versión 1.0 💪
